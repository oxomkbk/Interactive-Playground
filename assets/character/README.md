# Player character slot

Put a rigged glTF binary here named `hero.glb` with animation clips whose names contain `Idle`, `Walk`, `Run`
and (optionally) `Jump`. Sweetheart Park detects it at load and replaces the built-in procedural placeholder
character, scaled to 1.66 m. Check the model's licence before committing it, and record it in the root README's
asset table.
